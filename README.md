# DzinLabs Gaming VPN

All-in-one gaming VPN + game booster for Android. Created by Dominic.

- **WARP VPN** (Cloudflare) — one-tap connect, no account needed
- **Shizuku quick boost** — in-process game booster, no app switching
- **Floating boost bubble** — boost without leaving your game
- **Game tiles** — eFootball, PUBG, MLBB, Free Fire, CODM, Genshin, FC Mobile, Roblox
- **Tools** — HUD overlay (FPS / ping / battery temp), network check, reflex trainer, device dashboard
- **8 built-in boost scripts** — including universal `beast_mode.sh` (auto-detects Xiaomi / POCO / Redmi / Red Magic)

## Download

Get the latest APK from [Releases](../../releases). Install directly — no build tools needed.

## Requirements

- Android 8.0+
- [Shizuku](https://shizuku.rikka.app/) running (for boost features)

## Notes

- Updates install over the existing app (package `com.zeus.warpwg`) — your WARP registration is kept.
- Booster features use only stock Android / Shizuku-level settings. No game files are modified.
